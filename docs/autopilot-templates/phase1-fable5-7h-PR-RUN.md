This is **not** a full-launch or stacked-PR prompt. It is the safe owner pre-launch contract for one
unattended, bounded, launcher-ready slice. One Claude Code session runs in one feature worktree and ends at
`READY_FOR_MANUAL_MERGE` or a watchdog-visible `HALT-*` sentinel. It never moves to a dependent slice while
the founder is offline.

## 1. Why the run is intentionally single-slice

- `scripts/autopilot-scope-gate` treats a dependency that is still `in-flight|ready` as **not merged** and
  raises `DEP_MISSING`. A branch merely existing is not dependency satisfaction.
- Every feature/session owns its own worktree. A session may not switch among feature branches or reuse the
  historical `.autopilot/worktrees/phase1-fable5` worktree.
- P0 is manual-only. Canonical v0.6.0 classifies any scope touching auth/token, billing/funding/transactions,
  migrations, or secrets as P0. Such work must not be code-generated by unattended autopilot.
- A second slice starts only after the founder merges the first slice, verifies the merge on `origin/main`,
  runs scope-gate cleanup, authors the next complete artifact set, and opens a fresh worktree/session.

The seven-hour window is a ceiling for the selected slice, not permission to widen scope or chain PRs.

## 2. Eligibility gate

A task is eligible only when **all** are true on current `origin/main`:

1. `docs/autopilot-backlog.md` says `status: ready` — `idea` and `planned` are not runnable.
2. A committed manifest, `docs/autopilot-<slug>.md` task contract, and `.claude/commands/ap-NN-<slug>.md`
   launcher all exist on `origin/main`.
3. The manifest uses `base_ref: main`; every `depends_on` item is merged and not active in
   `.autopilot/INFLIGHT.md`; every `dep_checks` symbol exists on `main`.
4. The task passes the canonical risk self-check. Any auth/token/billing/funding/transactions/migration/
   secret scope is P0 and therefore ineligible for unattended codegen.
5. No existing worktree or branch already owns the slug. Never delete or reuse one without first proving its
   merge/forensic status and completing the prescribed cleanup.
6. `main` is clean and `HEAD == origin/main`; required artifacts are committed and pushed before worktree
   creation. Local-only authority docs do not count.
7. The manifest scope is bounded to roughly three modules / 300 non-test LOC and has no collision with an
   active invariant token or file scope.

## 5. Runtime contract inside the selected worktree

### 5.1 Time, state and scope

- Record `T0=$(date +%s)`, `HARD_STOP=$((T0 + 7*3600))`, and a 20-minute finish margin.
- Before editing create `.autopilot/state/infra-egress-compatibility-evidence/regions.log` and
  `.autopilot/state/infra-egress-compatibility-evidence/fix-round-count.txt` with initial count `0`.
- Edit only `docs/standards/environments-setup.md`. Do not author App Specs/workflows, edit infra/application
  code, handle secret values, change migrations, provision resources, or start another task.
- If the hard stop arrives mid-slice, reach a safe commit, push only the feature branch if possible, write
  `.autopilot/state/infra-egress-compatibility-evidence/HALT-TIMEBOX.txt`, preserve the worktree and stop.

### 5.2 Evidence and verification gate

- Verify each of SePay, ApiPay, Zalo Bot and Meta Messenger independently. Distinguish Plexco's outbound API
  calls from inbound webhook validation; one does not prove the other.
- Prefer current, official provider documentation. If official documentation is silent, only an attributable
  provider support/contract response supplied by the owner can close that row. Search snippets, community
  posts and inference are not evidence.
- Record source URL/title, checked date, supported conclusion and a short paraphrase. Do not copy long text.
- All four rows proved → write exactly one overall result: `DO_VPC_COMPATIBLE` or `FIXED_EGRESS_REQUIRED`,
  update the checklist, and add the completion marker required by the task contract.
- Any missing or ambiguous row → write the worktree-local `HALT-EVIDENCE_INCOMPLETE.txt` sentinel and stop;
  do not add the completion marker or speculate.

Verification for this docs-only slice:

```bash
pnpm exec prettier --check docs/standards/environments-setup.md
git diff --check
git diff --stat main...HEAD
```

The last command must be non-empty and list only the manifest scope. No database or application suite is
required because this slice cannot modify code/config/schema; any scope expansion invalidates that exemption.

### 5.3 Codex review

- Resolve only the pinned binary:
  `CODEX="${AUTOPILOT_CODEX_BIN:?HALT CODEX_UNAVAILABLE}"`; require it to be executable.
- Confirm `git diff --stat main...HEAD` is non-empty, scope-exact and on the current HEAD before the round.
- Persist the round by direct redirection — never `tee`, PTY capture, PATH `codex`, or a substitute reviewer:

```bash
"$CODEX" review --base main \
  > ".autopilot/state/infra-egress-compatibility-evidence/round-01.txt" 2>&1
```

- P2 docs-only requires one FULL-base round with zero findings and a real tail verdict on the current HEAD.
- A finding triggers one bounded fix round: append `file:section` to `regions.log`, increment the file counter,
  re-run verification, commit, and review the new HEAD. Counter `>5` is `MAX_ROUNDS`; the same region in three
  consecutive rounds is `REGION_THRASH`.
- Quota text is `CODEX_QUOTA` and halts. A surviving non-connector auth sentinel is `CODEX_UNAVAILABLE`;
  connector-only/empty output may retry the same round once, then halts if repeated. There is no degraded mode.

### 5.4 READY or HALT

After the clean round, finish in the same turn:

1. Re-run the docs verification commands.
2. Confirm the diff contains only `docs/standards/environments-setup.md`, the completion marker is present,
   the tree is clean, counters exist, and at least one real commit exists.
3. Confirm mergeability with
   `git merge-tree --write-tree origin/main feat/infra-egress-compatibility-evidence`.
4. Run `scripts/autopilot-scope-gate ready --manifest
   docs/autopilot-manifests/infra-egress-compatibility-evidence.json`.
5. Push only `feat/infra-egress-compatibility-evidence`; open a PR to `main` if GitHub access is available.
6. Emit `READY_FOR_MANUAL_MERGE` and stop. Do not merge, clean the reservation, remove the worktree, run AP-21,
   or start a second slice.

Every breaker writes `.autopilot/state/infra-egress-compatibility-evidence/HALT-<REASON>.txt` before the TUI
report. Any non-breaker founder decision writes `AWAIT-FOUNDER-<reason>.txt`. Both files live in this worktree.
