## 4. Threat model (lane block items 1-7, one line each with its defence)
1. A promoted player never told: the promotion stays deliverable while the start is ahead, on every path including the CLI backfill (R-CLI).
2. A stale DM after the start or after the promotion stopped being true: the definer expires at now >= start; 0057 refuses cancel, close, end and a left player (section 2). Residuals: a send may leave up to the 120 s attempt budget after the start (`ATTEMPT_BUDGET_MS`, `zalo-dm.ts:29`, one recipient); not measured (low): a rejoin that reuses the old player row and its `joined_at`.
3. Clock error: one DB clock, `clock_timestamp()` against `starts_at` in one statement; no Date.now() or options.now in the decision.
4. Bypasses: `deliver()` has one call site (`dispatcher.ts:309`, threat note `:88`); phase 2 claims only enabled projectors (`:277-279`) through the live claim (`:286-290`); raw or CLI re-enable, rollback-resumed rows, retries and DLQ replay (`0056:243-273`, `scripts/outbox-dlq-replay.mjs:84-85`) all pass it; a replay skips recorded recipients (Z-8, `zalo-dm.ts:20-24`).
5. A silent drop: every expiry completes as `delivered`/`noop_expired` with one line; a lost claim writes nothing and is re-checked at reclaim; the CLI's `age` and `cap` classes keep their `job_audit_events` record (`outbox-projector-enable.mjs:200-205`).
6. Drift of the bound or the exception: one JSON list read by both consumers with load checks; PSD-11 ties it to the definer's type literal in both directions; a new type needs a migration.
7. An unreadable start: NULL, a non-number or a non-finite value expires with the "start unreadable" line; a missing or foreign-tenant session is NULL; one rule for the whole class.
