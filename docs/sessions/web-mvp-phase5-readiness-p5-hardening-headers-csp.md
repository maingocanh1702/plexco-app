## 8. Security notes (checked line by line by the reviewer and the security round)

- S1. Meta CSP (D1; not built: D1's fallback). Official sources (P6, accessed 2026-10-29). CSP3 §3.3, https://www.w3.org/TR/CSP3/#meta-element: "The Content-Security-Policy-Report-Only header is not supported inside a meta element." "Neither are the report-uri, frame-ancestors, and sandbox directives." and a meta-delivered policy "...will be enforced along with any other policies active for the protected resource, regardless of where they're specified." So the meta's `frame-ancestors 'none'` is ignored and its other directives are enforced together with the global header CSP: strictly additive. Framing, HTML §7.7, https://html.spec.whatwg.org/multipage/speculative-loading.html#the-x-frame-options-header ("check a navigation response's adherence to X-Frame-Options"): step 2.1 "If policy's disposition is not "enforce", then continue." step 2.2 "If policy's directive set contains a frame-ancestors directive, then return true." step 8 "If xFrameOptions[0] is "deny", then return false." So the global HEADER CSP `frame-ancestors 'none'` (NC:62) governs framing in a CSP-capable browser and X-Frame-Options DENY (NC:56) is the fallback; both stay unchanged.
- S2. Meta referrer (D1). HTML §4.2.5.1, https://html.spec.whatwg.org/multipage/semantics.html#meta-referrer: "If value is a referrer policy, then set element's node document's policy container's referrer policy to policy." "Only the most-recently-inserted or most-recently-modified meta element in this state has an effect." D1's F4 design gives the landing one referrer meta `strict-origin`, before the form and the script, so the completion POST goes out under `strict-origin`: a real Origin (D1.0's Fetch quote: only an https request to a non-https URL loses it) and a Referer of the origin only, so the callback URL's code and state stay out of the referrer (SCK:286's intent, which `no-referrer` met only by breaking the sign-in). Not built (D1's fallback): the landing keeps NC's global strict-origin-when-cross-origin (K0), as at base; the END row (W4) carries the meta and its browser check.
- S3. D3 only replaces Referrer-Policy on `/session/:slug` with a stricter value and adds X-Robots-Tag (K1, one header line); the global entry and every other path are unchanged (A-1, A-8).
